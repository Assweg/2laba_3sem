## Пример запуска

Запускайте программу из каталога задания, чтобы относительные пути к данным оставались корректными.

```bash
cd zad1
c++ -std=c++17 main1.cpp -o task1
./task1
```

Для остальных заданий используйте соответствующий `mainN.cpp`. Условия и примеры ввода находятся в `Help*.txt`, где такие файлы есть.
